## Launch proof

Do not lead with abstract claims. Lead with three reproducible fixtures:

1. Generic AI micro-SaaS -> route closed.
2. Local SME workflow integration -> narrow paid test supported.
3. Local care/public-service navigation -> local and responsibility-bearing route supported.

## First issues

1. Add a fourth independently sourced opportunity fixture.
2. Add an opportunity evidence-signature format.
3. Add a low-connectivity public-employment deployment profile.
4. Add calibration data while preserving participant privacy.
5. Translate reason codes without changing semantics.

## Release message

> AI can make software. That does not mean the market needs another copy. ClearPath exposes funded demand, qualified supply, first-mover capture, training-seat inflation, and DIKWP evidence before a person spends months on a route. It can say “go,” “test cheaply,” “pivot,” or “stop for now” - and it never turns a closed route into a judgment about human worth.

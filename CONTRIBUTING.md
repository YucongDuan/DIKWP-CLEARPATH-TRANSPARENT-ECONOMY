# Contributing

Contributions are welcome in four high-value categories:

- new opportunity fixtures with independently checkable denominators;
- jurisdiction- or sector-specific transparency profiles;
- falsification tests and failure cases;
- interoperability adapters that preserve privacy and human authority.

A pull request should include:

- the problem and affected users;
- the changed assumption or invariant;
- tests;
- a synthetic example;
- limitations;
- confirmation that no person-level worth score or automatic high-impact action was added.

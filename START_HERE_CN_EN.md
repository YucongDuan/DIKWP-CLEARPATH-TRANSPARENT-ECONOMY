# Start Here / 快速开始

## Browser / 浏览器

1. Open `DIKWP_CLEARPATH_TRANSPARENT_ECONOMY_OS_v1.0.0.html`.
2. Choose a preset or enter one concrete route.
3. Enter the number of funded paid slots, qualified supply, new entrants, price, cost, automation share, access requirements, and training seats marketed.
4. Enter only the personal constraints required for the decision.
5. Run the analysis.
6. Treat `NO_CURRENT_VIABLE_PATH` as a stop-spending instruction for this route, not a judgment about the person.
7. Export the JSON or Markdown receipt.

1. 打开单文件 HTML。
2. 选择预设或填写一条具体机会路径。
3. 填写真实付费名额、当前供给者、新增供给者、价格、成本、自动化比例、入口要求和培训席位。
4. 只填写本次判断真正需要的个人约束。
5. 运行分析。
6. 将“当前无可行路径”理解为停止继续投入，而不是评价人的价值。
7. 导出 JSON 或 Markdown 收据。

## A good first reality test / 合格的第一次现实验证

A valid test has:

- a named buyer or funder;
- a narrow deliverable;
- a written acceptance condition;
- a price or value commitment;
- a maximum time and money loss;
- a stop condition;
- a receipt that can disprove the route.

有效试验至少具有：具名买方或出资方、窄成果、书面验收、价格或价值承诺、最大损失、停止条件，以及能够否定该路径的现实收据。
